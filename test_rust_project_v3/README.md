# test_rust_project_v3

## Overview

This is a test Rust binary crate implementing a simple agent system with planning, execution, and tool usage.

## Build

```bash
cargo build
```

## Run

```bash
cargo run
```

## Architecture

- `agent.rs` — orchestrates the system
- `planner.rs` — generates execution plans
- `executor.rs` — executes plans
- `tools.rs` — utility tools used by the agent

This project will be expanded incrementally toward a more advanced agentic system (~2000 LOC).
